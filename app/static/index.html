    AI features

    Use Claude for receipts, voice, questions & insights

    Privacy: Claude only sees what you send for that feature, with account numbers and balances removed. That means a receipt you scan, a sentence you speak or type, a question you ask, or monthly totals. It never sees your full ledger.

    Automation

    Send every bank or UPI SMS here, and Artha logs it without you typing anything:

    POST JSON {"message": "<sms text>"} with header X-Token, or add ?token= to the URL. In MacroDroid, use “Notification received (Messages)” → “HTTP request”. The README has step-by-step instructions. Set ARTHA_WEBHOOK_TOKEN on the server so your automation app gets a token that can only add payments.
